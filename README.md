# Lenta 

Lenta — это современный персональный органайзер, объединяющий наглядность временной шкалы, гибкость календаря и простоту мессенджера для быстрых заметок.

## Ключевые возможности

### 📏 Timeline (Таймлайн)
- **Статическая система координат**: Высокая стабильность жестов и плавное масштабирование.
- **Визуализация "Времени на дорогу"**: Отображение времени до и после события в виде полупрозрачных блоков.
- **Умная раскладка**: Автоматическое распределение задач по дорожкам для предотвращения перекрытий.
- **Индикация времени**: Красная линия текущего времени и детальная сетка (шаг 15/30 мин).
- **Weekday Labels**: Четкие метки дней недели для удобной навигации.

### 🗓️ Calendar (Календарь)
- **Бесшовный вертикальный режим**: Непрерывная лента дней с жирными разделителями месяцев.
- **Фоновые индикаторы месяцев**: Крупные водяные знаки с номерами месяцев для ориентации при быстром скролле.
- **Глубокая кастомизация**: Настройка цвета сетки, прозрачности бара дней, яркости списка задач и цвета маркера текущего дня.
- **Два режима отображения**: Классическая горизонтальная сетка и расширенный вертикальный список.

### 💬 Easy Mode (Заметки-Чаты)
- **Система тематических чатов**: Группировка заметок по категориям. Каждая группа (чат) имеет свое название и цветовую метку.
- **Гибкие режимы сообщений**: Поддержка простых текстовых сообщений и списков дел с чекбоксами. Настройка режима применяется индивидуально к новым записям.
- **Режим Чата (Messenger Style)**: Опциональное отображение сообщений снизу вверх с автоматической прокруткой к новым записям.
- **Стабильный интерфейс**: Закрепленный заголовок и поле ввода, которое идеально прилегает к клавиатуре без лишних зазоров.

### ⚙️ Настройки и Персонализация
- **iOS-style интерфейс**: Сгруппированные настройки с интуитивной навигацией по разделам (Оформление, Таймлайн, Приложение).
- **Управление видимостью**: Возможность скрыть редко используемые поля в редакторе задач (Location, URL, Описание и др.).
- **Темы оформления**: Полная поддержка темной и светлой тем с возможностью ручной настройки цветов.

### 🔄 Рекуррентные задачи и Multi-day
- **Циклы повторений**: Поддержка ежедневных, еженедельных и других правил повторения событий.
- **Групповое управление**: Умное удаление ("Только это" или "Все последующие") в серии повторений.
- **Multi-day создание**: Быстрое дублирование задачи на несколько выбранных дат одним нажатием.

## Технологический стек
- **Язык**: Kotlin 2.x
- **UI**: Jetpack Compose (с использованием современных подходов Edge-to-Edge)
- **Архитектура**: MVVM + StateFlow + AndroidViewModel
- **База данных**: Room (v6) с TypeConverters для перечислений
- **Хранение настроек**: SharedPreferences для мгновенного применения UI-параметров.
- **Библиотеки**: Compose Calendar (Kizitonwose)

## Текущее состояние
Проект сфокусирован на полировке пользовательского опыта (UX) и создании максимально отзывчивого интерфейса. Особое внимание уделено стабильности работы с клавиатурой и системными инсетами.
