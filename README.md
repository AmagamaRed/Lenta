# Lenta - Smart Productivity App

Приложение для гибкого планирования задач с визуализацией на временной шкале и календаре.

## Основные возможности

### 〰️ Timeline (Лента)
- **Масштабируемая шкала**: поддержка зума для детального планирования.
- **Умная раскладка**: автоматическое решение конфликтов накладывающихся задач (разнесение по разным "дорожкам").
- **Гибкие диапазоны**: просмотр расписания на 1, 3, 7 или 14 дней.
- **Индикация времени**: красная линия текущего времени и удобная сетка с шагом 30 и 15 минут.

### 🗓️ Calendar (Календарь)
- **Два режима**:
    - **Горизонтальный (Г)**: классическая сетка месяца с индикаторами-точками.
    - **Вертикальный (В)**: вытянутая сетка с плашками задач и поддержкой длинных названий.
- **🎯 Быстрый возврат**: кнопка мгновенного перехода к текущей дате.
- **Всплывающие списки**: детальный просмотр задач дня в Modal Bottom Sheet.

### 💬 Easy Mode
- Режим быстрых заметок и чек-листов для оперативного планирования "на лету".

## Технологический стек
- **Язык**: Kotlin
- **UI**: Jetpack Compose
- **Архитектура**: MVVM + StateFlow
- **База данных**: Room (SQLite)
- **Библиотеки**: Compose Calendar (Kizitonwose)
